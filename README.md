# Product-Performance-Dashboard
Project Overview

This project focuses on analyzing chocolate sales data to understand product performance, sales trends, and customer purchasing behavior. The analysis includes data cleaning, exploration, and visualization to generate meaningful business insights.

🎯 Objectives
Analyze overall sales performance
Identify top-performing products
Understand sales trends over time
Perform data cleaning and preprocessing
Generate insights for business decision-making
🛠️ Tools & Technologies
Python
Pandas
Matplotlib
Seaborn
Power BI (for dashboard visualization)
Microsoft Excel
📂 Dataset

The dataset contains chocolate sales data including:

Product details
Sales amount
Date of transaction
Other relevant attributes
⚙️ Data Processing Steps
Loaded dataset using Pandas
Performed initial data exploration (head(), info(), describe())
Cleaned column names (removed extra spaces)
Converted date column into datetime format
Cleaned and formatted amount column (removed symbols, converted to numeric)
📊 Analysis Performed
Sales distribution analysis
Time-based sales trends
Product performance evaluation
Correlation and pattern identification
📈 Visualization
Bar charts for product comparison
Line plots for sales trends
Distribution plots for sales analysis
📊 Dashboard

An interactive dashboard was created using Power BI to visualize:

Total Sales
Product-wise performance
Sales trends over time
Key business insights
🚀 Key Insights
Identified high-performing products contributing to major revenue
Observed trends in sales over time
Highlighted patterns useful for decision-making

This project demonstrates the end-to-end data analysis process including data cleaning, exploration, visualization, and dashboard creation to derive actionable insights.
